# Neymis Web

Лёгкий и быстрый браузер для Android на базе Android System WebView (Chromium).
Тёмная тема, фиолетовый акцент, нижняя панель для управления одной рукой.

<img src="icon.jpg" width="120" alt="Neymis Web">

## Возможности

- Несколько независимых вкладок: страницы не перезагружаются при переключении
- Инкогнито: розовая метка, без истории, очистка кэша и куки при закрытии
- Умная адресная строка: ссылка → сайт, текст → Google, `file:///` → локальный файл
- Индикатор загрузки, назад/вперёд/обновить/стоп/домой
- Экран вкладок с карточками, закрытием и созданием новых
- **Eruda**: консоль JS, инспектор DOM, Network и LocalStorage прямо на телефоне
- Исходный код страницы: просмотр и сохранение в `.html` в `Загрузки/NeymisWeb`
- Версия для ПК: десктопный User-Agent
- Закладки и история, поиск по ним не требуется, но удаление есть
- Скачивания через системный DownloadManager с уведомлением
- Полноэкранный режим для видео и игр
- JavaScript, WebGL, LocalStorage и `<input type="file">`
- Системная кнопка «Назад» ведёт по истории сайта

## Разрешения

`INTERNET`, `ACCESS_NETWORK_STATE`, `WRITE/READ_EXTERNAL_STORAGE` (только до Android 10).

## Сборка

```bash
gradle assembleDebug
```

Нужны JDK 17 и Android SDK 34. APK: `app/build/outputs/apk/debug/`.
